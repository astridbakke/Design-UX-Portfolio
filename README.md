# Design-UX-Portfolio

### **The Tokyo Toilet (2025)**
An editorial design booklet exploring the renowned public sanitation initiative in Shibuya, Japan. Inspired by Japanese minimalism and the film *Perfect Days*, the design showcases 17 unique public toilets created by world-famous architects.

* **Focus:** Editorial design, typographic hierarchy, grid systems, and print preparation.
* **Specs:** 32-page, 7”x 9” booklet designed for saddle-stitch binding.
